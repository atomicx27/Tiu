# Tiu Video Box Future Tasks (TODOS)

This document tracks technical debt and deferred features for future phases of Tiu's Birthday Video Box project.

## Deferred Features

### Cloudinary Folders & Tags Organization
- **What:** Add video tagging and folder-based sorting/navigation on the homepage gallery grid.
- **Why:** If the collection grows to dozens or hundreds of birthday videos, browsing a single large bento grid will become difficult.
- **Pros:** Allows categorizing videos (e.g. "Cake Cutting", "Wishes", "Funny Moments", "Family") for a highly organized, easy-to-navigate gift gallery.
- **Cons:** Slightly increases complexity of the homepage layout, and requires adding a tag selection dropdown/text input to the upload screen.
- **Context:** Deferred in Phase 1 to prioritize a clean, simple launch with a single grid list, where text search matches all video titles.
- **Depends on / blocked by:** None.
